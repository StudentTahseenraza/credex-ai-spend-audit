🚀 Quick Start
Prerequisites
Node.js 18+

MongoDB Atlas account (free)

OpenRouter API key (free $1 credit)

Resend API key (free 3k emails)

Installation

    # Clone the repository
    git clone https://github.com/yourusername/credex-ai-spend-audit.git
    cd credex-ai-spend-audit

# Install dependencies
    npm install
    
    # Copy environment variables
    cp .env.example .env.local

# Edit .env.local with your keys

    # Run development server
    npm run dev
Environment Variables
    env
    # MongoDB Atlas
    MONGODB_URI=mongodb+srv://username:password@cluster.mongodb.net/
    MONGODB_DB_NAME=credex_audits
    
    # OpenRouter (GPT-3.5 Turbo)
    OPENROUTER_API_KEY=sk-or-v1-xxxx
    OPENROUTER_BASE_URL=https://openrouter.ai/api/v1
    OPENROUTER_MODEL=openai/gpt-3.5-turbo
    
    # Resend Email
    RESEND_API_KEY=re_xxxx
    RESEND_FROM_EMAIL=onboarding@resend.dev
    
    # App URL
    NEXT_PUBLIC_APP_URL=http://localhost:3000
Deployment

    # Deploy to Vercel
    vercel --prod
    
    # Or build locally
    npm run build
    npm start
    
📡 API Reference
    POST /api/audit
    Generate AI spend audit report.
    
    Request Body:
    
    json
    {
      "tools": [
        {
          "name": "chatgpt",
          "plan": "Team",
          "monthlySpend": 50,
          "seats": 2
        },
        {
          "name": "cursor",
          "plan": "Business",
          "monthlySpend": 80,
          "seats": 2
        }
      ],
      "teamSize": 4,
      "useCase": "coding",
      "email": "founder@startup.com",
      "company": "Acme Inc"
    }
    Response:
    
    json
    {
      "success": true,
      "shareableId": "abc123xyz",
      "totalMonthlySavings": 70,
      "totalAnnualSavings": 840,
      "tools": [...],
      "aiSummary": "Based on your coding-focused team of 4...",

      "emailSent": true

# 🤝 Key Decisions & Trade-offs

| Decision | Reasoning |
|---|---|
| Hardcoded audit rules instead of AI-generated recommendations | Financial recommendations need to be deterministic, explainable, and traceable rather than hallucinated by an LLM |
| Next.js over standard React SPA | Server-side rendering and dynamic OG image generation improve shareability and SEO |
| MongoDB over Postgres | Flexible schema structure fits evolving audit payloads and recommendation metadata |
| Fallback AI summary system | Ensures the product remains functional even during API rate limits or provider failures |
| localStorage persistence | Prevents accidental form loss and improves UX without requiring authentication |
| Multi-step form UX | Reduces cognitive overload and improves completion rates for cold users |
